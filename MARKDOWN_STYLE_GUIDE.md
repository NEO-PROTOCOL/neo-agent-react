# Guia de Estilo Markdown (MARKDOWN_STYLE_GUIDE.md)

Este guia estabelece os padrões para escrever arquivos `.md` no projeto `neo-agent-react`.

## Regras

1. **Linter:** O projeto assume as regras padrão listadas no topo do `README.md` (por exemplo: desabilita `MD033` para permitir tags HTML caso necessário).
2. **Cabeçalhos:** Utilize o prefixo `#` adequadamente. O topo do arquivo deve conter um único `# Título`.
3. **Listas:** Utilize `-` para bullet points e espaço de linha antes de iniciar listas.
4. **Alertas e Destaques:** Utilize sintaxe do GitHub (ex: `> [!WARNING]`) para destacar informações importantes, críticas, ou de risco em arquivos operacionais.
5. **Formatação de Códigos:** Especifique sempre a linguagem nos codeblocks (ex: ````bash ```` ou ````typescript ````).

Qualquer agente gerando ou alterando documentação DEVE seguir este guia para garantir uniformidade.
