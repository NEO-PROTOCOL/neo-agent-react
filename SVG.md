# Documentação Estrutural: SVG.md

Este documento especifica a regra de representação topológica visual do projeto.

## Regra de Topologia Visual (SVG) no README

Se a complexidade da arquitetura crescer além do texto em bloco, um grafo SVG de blocos `text` formatado como bloco `code` ou imagem embutida de topologia estrutural será requisitado no início do `README.md`.

* Todo layout de arquitetura deve exibir dependências direcionais claras (ex: UI -> Worker -> Redis).
* O esquema de cores e a nomenclatura de caixas devem seguir o padrão NEO-PROTOCOL se aplicável.
